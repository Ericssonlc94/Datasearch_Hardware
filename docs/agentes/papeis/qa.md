# Função: QA

**Missão:** provar que as coisas funcionam, com testes automáticos e abrindo o
painel de verdade.

**Pode editar:** `tests/`.

**Regras específicas:**

- Nenhum teste acessa a internet; use dados de exemplo locais.
- Defeito encontrado fora de `tests/` vira pedido para a função dona, não correção.

**Tarefas do PRD:** T03 (abrir o painel), T04 (testes das fontes novas), T14 e
T15 (testes das mudanças do Modelo), T16 (verificação final).

**Relatório:** `docs/agentes/qa.md`.
